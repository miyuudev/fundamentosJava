# JAVA 入門復讐

Java é uma linguagem de programação orientada a objetos, fortemente tipada e amplamente utilizada no desenvolvimento de aplicações backend, mobile e sistemas corporativos. Um dos seus principais diferenciais é a **portabilidade**, possibilitada pela *JVM (Java Virtual Machine), que executa o código compilado (bytecode) em diferentes sistemas operacionais sem necessidade de alteração.* Essa abordagem permite que o princípio “write once, run anywhere” seja aplicado, tornando o Java uma escolha robusta, segura e escalável para diversos tipos de aplicações.

## Tipos primitivos

> Numeros inteiros  
byte => 8 bits => -128 a 127  
short => 16 bits => -32.768 a 32.767  
int => 32 bits => -2.147,483,648 a 2.147,483,647  
long => 64 bits => -9.223,372,836,854,775,808 a 9.223,372,836,854,775,807  

> Numeros decimais  
float => 32 bits => precisao simples  
double => 64 bits => precisao dupla (padrao)  
boolean => true/false  
char => caractere

> Use BigDecimal para representar dinheiro
